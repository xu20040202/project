# Project Overview

UE5 behavioral prototype project.

Current prototype:
Crow / Delay Relation

Goal:
Create a playable prototype where the player pursues a crow that always remains slightly unreachable.

# Technical Rules

- UE5
- Blueprint-first workflow
- C++ for reusable systems
- Do not modify project settings
- Do not add external plugins
- Do not generate complex art assets
- Do not refactor the whole project

# Current Tasks

Allowed:
- Add C++ classes
- Add Actor Components
- Add Structs / Enums
- Add Debug systems

Forbidden:
- Modifying existing Content assets
- Breaking Blueprint references
- Editing rendering pipeline
- Replacing input systems
